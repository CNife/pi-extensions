# Prototype — 可丢弃原型

独立辅助技能，**不入流水线**，有代码层不确定性时随时调用。

## 两种形态

### 终端原型

跑一个最小可执行脚本，验证状态机/业务逻辑/算法是否说得通。

- 范围：只验证一个具体问题
- 产出：能跑的命令或脚本
- **用完就扔**，不在原型基础上迭代

### UI 原型

同一路由下放多个风格迥异的 UI 方案，切换对比视觉效果。

- 范围：只验证视觉方向
- 产出：可交互的页面
- 选完就扔

## 结论写入

原型验证完成后，将结论写入当前变更的 `plan.md`「原型验证」节：

```markdown
## 原型验证

- **问题**：{验证的具体问题}
- **方法**：{终端原型 / UI 原型}
- **结论**：{验证结果及对方案的影响}
```

## 停止条件

- 原型跑完 + 结论写入 → 停止
