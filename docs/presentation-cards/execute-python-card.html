bash 可以执行任何任务，但不适合写 python -c "长长长串代码"。

bash 跑 Python 的痛点

  • 引号与换行需要转义，模型容易写坏命令
  • 依赖需手动安装或提前准备虚拟环境
  • 纯文本输出，缺少结构化信息与语法高亮

executePython 的解法

  • 代码直接写入临时文件，无需 bash 转义层
  • uv 自动管理依赖
  • 结构化返回：exitCode / stdout / stderr / 耗时
  • TUI 语法高亮 + 实时流式输出
