@cnife/pi-simple-plannotator

  • 不做 plan mode、配置系统等额外包装
  • 收敛成三个自定义命令：/pnr · /pna · /pnl

三个 slash command，刚好够用

/pnr 审查本地 git 变更
/pna 标注 Markdown 文件或文件夹
/pnl 标注最后一条 AI 消息
