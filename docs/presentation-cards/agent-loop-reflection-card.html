v0.2.0

没有反思

  • Flash 级别模型容易忘掉最初的指令，跑偏了也不知道
  • 一条路走不通，换条路继续撞墙
  • 大量 token 和时间浪费在无意义的循环上

强制反思

  • 定期暂停检查：还在服务用户的原始目标吗？
  • 卡住了？调 advisor 从更强模型获取建议
  • 不确定？停下来等用户给方向，不作无谓尝试

默认每10个 turn 插入一次反思提醒

插件通过 steer 以用户消息的形式插入当前 agent 流程，模型必须停下处理。默认提醒内容：

请先暂停继续推进，做一次 agent loop 反思：

1. 回到用户的原始目标：现在正在做的事是否仍然直接服务于这个目标？
2. 检查当前证据和方向：已经验证了什么，哪些只是猜测，下一步是否仍然是最小有效动作？
3. 判断是否卡住、不确定或可能跑偏：如果是，请先调用 advisor 获取建议，再继续。

如果一切仍然清晰，请用一两句话说明判断依据，然后继续执行。

提醒后的反思 turn 不计入下一次倒计时。用户在任何时候介入（输入消息）也会重置计数器。

不乱打断三种情况不触发提醒

  • 短任务——turn 数未达阈值，模型很快就结束了，不需要打断
  • 用户介入——用户输入新消息后倒计时重置，用户已经接手就不额外提醒
  • 回复结束——stopReason 不是 toolUse（模型已生成最终回复），不触发提醒

3 个 Pi 扩展面

Pi 扩展面代理循环反思如何使用
turn_end递减倒计数器，满足条件时触发提醒
input监听所有消息来源，非插件来源时重置倒计时
