用四个指标抓住 LLM 缓存失效的瞬间

看到 R 下降、M 上升，就意味着缓存失效，你多花了钱。

M = Cache Miss Tokens失效 Token

M 是被浪费的输入 tokens，直接回答一个问题："本应命中的缓存没命中，多花了多少 token？"

M = Σ max(0, baselinePrompt − cacheRead)

M 是绝对值，不是百分比——每 1 个单位都对应实实在在多送进模型的 token，是衡量缓存效率最直接的经济度量。

R = Real Cache Hit Rate有效命中率

R 由 M 推导而来：M 占总输入（非缓存读取部分）的比例就是缓存浪费率，100% 减去它就是有效命中率 R。缓存最优时 R=100%，完全没有浪费。

R = (1 − ΣMiss / (ΣpromptTokens − ΣcacheRead)) × 100

轮边界算法：正确计算有 CacheWrite 的场景

OpenAI completions无 cacheWrite

每条请求的 promptTokens 不含写入开销，cacheRead / promptTokens 直接反映真实命中率。

Anthropic messages有 cacheWrite

写入缓存的 token 也被计入 promptTokens，拉大了分母。写入消息低、复用消息高，同轮内剧烈波动。

轮边界算法按用户消息切回合，前一回合最后一条助理消息的 promptTokens 作为后一回合基线。只有跨回合才计失效，同轮内 cacheWrite 的波动被完全隔离：

baselinePrompt = 上一轮最后一条 asst msg 的 promptTokens
Miss = max(0, baselinePrompt − cacheRead)

模型切换或 compaction 时全部归零，从新上下文重建累计状态。
