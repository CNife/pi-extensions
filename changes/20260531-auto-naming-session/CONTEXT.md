# 20260531-auto-naming-session

本次变更新增或修改的项目用语。

## 新增

**auto-naming-session**：
一个 pi 扩展，在会话 turn 结束时自动生成并更新会话标题。
_避免_：session-naming、auto-title（与已有包名冲突）

**首次生成**：
会话的第一个 turn 结束时触发的标题生成。所有会话（含恢复旧会话）均触发。
_避免_：初始生成、首轮生成

**自动刷新**：
按 `auto_refresh_turns` 配置的间隔（会话总 turn 数）周期性触发的标题刷新。
_避免_：定时刷新、轮询刷新

**手动标题保护**：
当检测到用户通过 `/name` 等方式手动修改了标题后，插件不再覆盖。
_避免_：手动覆盖保护

**lastEntryId 追踪**：
每次标题生成时记录 branch 中最后一个 entry 的 ID，下次只取该 ID 之后的消息作为上下文。
_避免_：消息指针、游标

**turn 计数**：
从会话开始累积的总 turn 数。auto_refresh 检查从 turn 11 开始触发（默认 10）。
_避免_：自上次刷新计数
